# One-Liner Laugh Lab — The Alarm's Confession


A program that writes one short funny line to `/output/entry.txt` — the excuse an alarm clock gives for why you overslept:

> "I didn't oversleep. I snoozed myself. We're both late now."

Run: `node main.ts` (Node 22). No network, no dependencies.
